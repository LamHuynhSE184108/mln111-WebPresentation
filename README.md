# Website Thuyết Trình Triết Học: "Xác Định Chân Lý Trong Xã Hội Bất Định"

Ứng dụng thuyết trình hiện đại về triết học, tập trung vào chủ đề xác định chân lý thông qua các trường phái triết học và thực tiễn đời sống.

## Công nghệ sử dụng
- **Next.js 14 (App Router)**: Framework React mạnh mẽ.
- **Tailwind CSS**: Thiết kế giao diện hiện đại, tối giản.
- **Framer Motion**: Hiệu ứng chuyển động mượt mà và Horizontal Scroll.
- **Lucide React**: Hệ thống icon tinh tế.

## Các tính năng chính
1. **Hero Section**: Giới thiệu chủ đề với hiệu ứng Parallax và câu trích dẫn dẫn nhập.
2. **Theory Section**: Cuộn ngang (Horizontal Scroll) để khám phá 5 trường phái triết học lớn.
3. **Nature Section**: 3 tính chất cơ bản của chân lý với hiệu ứng Hover.
4. **Application Section**: Phân tích thực tiễn thông qua lưới Grid so sánh Đám đông, Lợi ích và Chân lý.
5. **Interactive Chatbot**: Mô phỏng hỏi đáp về các tình huống triết học.
6. **Dot-navigation**: Thanh điều hướng cố định bên phải để di chuyển nhanh.

## Cài đặt và Chạy dự án
1. Cài đặt dependency:
   ```bash
   npm install
   ```
2. Chạy môi trường phát triển:
   ```bash
   npm run dev
   ```
3. Truy cập: `local: http://localhost:3000`

## Cấu trúc thư mục
- `src/app`: Chứa layout và trang chính.
- `src/components`: Các thành phần giao diện (Hero, Theory, Nature, v.v.).
- `src/lib`: Các hàm tiện ích.
- `src/app/globals.css`: Cấu hình màu sắc (Cobalt Blue & Deep Purple) và CSS theme.
